# DSA-in-Cpp 💀

A collection of **Data Structures and Algorithms (DSA) solutions in C++**, primarily covering problems from [LeetCode](https://leetcode.com/) and [GeeksforGeeks](https://www.geeksforgeeks.org/).

This repository documents my problem-solving journey, helps me revise important concepts, and builds consistency for coding interviews.

## 📚 What You'll Find

- Solutions to coding problems organized by problem number and name
- Practice with arrays, strings, matrices, recursion, and other DSA topics
- C++ implementations focused on understanding algorithmic logic
- LeetHub-synced solutions for supported LeetCode problems

## ▶️ Run a Solution Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/DSA-in-Cpp.git
   ```

2. Enter the repository and open the folder for the problem you want to run.

3. Compile the relevant C++ source file with a C++ compiler, for example:

   ```bash
   g++ -std=c++17 solution.cpp -o solution
   ```

4. Run the compiled program:

   ```bash
   ./solution
   ```

> **Note:** Some LeetCode and GeeksforGeeks submissions use platform-provided function signatures or classes such as `Solution`, rather than a standalone `main()` function. Those files may need a platform-compatible driver before they can run independently.
